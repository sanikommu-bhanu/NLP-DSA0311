# Capstone Project

Organize capstone work in the appropriate subfolder:

- `PPT/` — presentation files and slide-related materials.
- `Reports/` — project reports and written documentation.
- `Datasets/` — datasets used in the project. Add only data you are permitted to use.
- `Source-Code/` — project source files and related implementation materials.

Add your own project materials; no sample code or datasets are included.
